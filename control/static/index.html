ЭТАП 2 · ГОТОВНОСТЬ КОМПЬЮТЕРА

Проверка среды

Проверьте WSL 2, Ubuntu, Docker Engine и Compose.

На Windows используется Ubuntu 24.04 LTS в WSL 2; Docker Desktop не требуется. Загрузка и образы требуют несколько ГБ свободного места. Права Docker дают широкие возможности на компьютере. Автозапуск включается только вашим действием; в Linux хранилище нужно разблокировать после входа.

Если система запросит UAC или перезагрузку, завершите этот шаг и снова откройте панель. Для неподдерживаемой системы: официальная установка Docker · установка WSL.

Восстановить из файла

Сначала проверяем версию и целостность. Замена данных требует отдельного подтверждения.

Перенос на другой компьютер

Передайте совместимую поставку, скачанный архив и ключ отдельно. После восстановления старые очереди отправок приостанавливаются.

Подтвердите, что прежняя установка остановлена. ИИ будет отключён до ручного включения и не ранее чем через 24 часа, чтобы не восстановить уже израсходованную квоту.

Telegram подтверждает приём файла. Успешное восстановление проверяется отдельно.

ЭТАП 4 · РЕЗЕРВИРОВАНИЕ И ОПОВЕЩЕНИЯ

Telegram, хранение и ИИ

Один бот, два отдельных направления. Пустые секретные поля сохраняют прежние значения.

Копии данных

Бот должен иметь право отправлять документы. Копии зашифрованы; ключ храните отдельно.

Сбои и смена статусов

Gemini включается внутри платформы. Сохранение ключа не отправляет данные в ИИ.

Работа хаба

При входе в систему автозапуск поднимает основную сохранённую платформу и сворачивает хаб в трей.

Выключить хаб

Остановит платформу, закроет туннель и завершит приложение. Данные сохранятся.
