# Aion

Локальная платформа команды хакатона: Kanban с учётом времени, светофор и инциденты, аналитика, Argus, внутренние уведомления и административная песочница. Один сервис, одна папка данных, запуск на обычном ПК.

## Состояние проекта

Сейчас это **рабочий минимальный прототип**: основные пользовательские сценарии работают и покрыты pytest-тестами, часть интеграций и экранов — заглушки.

## Стек

- Backend: Python 3.12, FastAPI, SQLAlchemy 2, Alembic, SQLite (WAL), Pydantic v2.
- Frontend: React 18, TypeScript, Vite 5, чистый CSS (без UI-библиотек и роутера).
- Данные: папка `data/` (БД, Markdown-документы, резервные копии), общая для Docker и прямого запуска.

## Быстрый старт (Windows)

```powershell
.\start.bat
```

Нужен Python 3.12+. Панель открывается на `http://127.0.0.1:8787` с локальным ключом доступа, создаёт отдельное окружение и проверяет WSL 2 / Ubuntu / Docker Engine / Compose. Docker Desktop не нужен. В мастере выберите новую папку или **явное подключение существующей базы**, сохраните ключ оператора, соберите образ и запустите платформу. Закрытие браузера не останавливает её. На Linux: `bash start.sh`; хранилище Linux требует разблокировки после запуска. [Подробности и статус приёмки](docs/17-portable-operations.md).

Для разработки: `start.ps1 -Development` либо вручную:

```powershell
Set-Location backend
..\.venv\Scripts\python.exe -m alembic upgrade head
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# во втором окне
Set-Location frontend
npm install
npm run dev
```

В режиме разработки открыть <http://localhost:5173>. Здесь сохраняется прежний bootstrap из `APP_FIRST_ADMIN_*`; задайте собственный пароль. Для эксплуатации используйте панель и Docker: новая поставка не создаёт стандартный пароль или проект оператора.

## Docker

```powershell
# Предпочтительный запуск с отдельными данными и секретами:
.\start.bat
```

Панель создаёт собственный Compose-проект установки. Производственные frontend и API доступны на <http://127.0.0.1:8000>. Корневой `docker-compose.yml` — ручной шаблон; требует защищённый `HCC_RUNTIME_DIR`, ключ оператора и явный выбор данных. Самостоятельно подключать рабочую базу без остановки прежнего сервера нельзя.

## Проверка

```powershell
Set-Location backend
..\.venv\Scripts\python.exe -m pytest
```

В управляемой поставке `/health` проверяет БД, запись, свободное место и наличие фоновых потоков. Отдельная локальная панель показывает ресурсы и свежесть проверок. Тесты панели находятся в `control/tests`; реальные Telegram/fxTunnel проверяются только на согласованных тестовых направлениях.

## Роли

- `participant` — работа с задачами, таймерами, инцидентами, документами.
- `captain` — дополнительно: корректировка времени, подтверждение красных инцидентов, настройки ИИ, бэкапы и восстановление, голос за завершение проекта.
- `admin` — глобальная роль: пользователи, роли, IP-правила, дедлайн проекта, песочница, редактирование журнала.

Роли складываются; `admin` не привязан к проекту, `participant` и `captain` назначаются на проект.

## Принципы

- Сервер — источник истины: права, переходы, лимиты и таймеры проверяются в API, интерфейс лишь отражает их.
- Все времена в БД — наивный UTC; московское время используется только при отображении и вводе.
- Данные, документы и бэкапы лежат в `data/` и переносятся вместе с `.env`; секреты не попадают в репозиторий и API.
- Интеграции изолированы: сбой Telegram/ИИ не блокирует работу штаба.

## Имена модулей и границы ответственности

| Имя | Назначение |
|---|---|
| Aion | Платформа, циклы спринтов |
| Ouroboros Daemon | Локальный менеджер проектов, ключи и восстановление контейнера |
| Argus | ИИ-наблюдатель |
| Hermes | Telegram-оповещения |
| Agora | Kanban-доска |
| Chronos | Планирование и диаграмма Ганта |

Проекты создаются в Ouroboros Daemon: один проект — отдельная база, аккаунты и документы.
Одновременно запускается один проект; он же выбран для восстановления и автозапуска.
В Aion администратор создаёт аккаунты своей команды, настраивает чат, темы и частоту ИИ.
Секреты Gemini, Telegram и fxTunnel вводятся и удаляются в Ouroboros Daemon.

Старую многопроектную базу можно разделить кнопкой «Разделить старую базу на проекты».
Перед разделением платформа останавливается. Исходная папка сохраняется, каждая копия
проверяется на целостность. Сессии входа не копируются. Общие администраторы и участники
сохраняют пароли в независимых копиях; исторические авторы сохраняются для целостности.
Ключи новых установок задаются отдельно. Внешние действия после переноса нужно включить явно.
