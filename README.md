# Aion

Локальная платформа команды хакатона: Agora (Kanban и таймеры), Chronos (планирование), инциденты, аналитика и Argus (анализатор ситуаций). Hermes доставляет уведомления в Telegram. Ouroboros Daemon управляет запуском, изолированными проектами, ключами и восстановлением.

## Запуск

Для удалённого доступа на Linux VPS используйте [инструкцию веб-развёртывания](deploy/vps/README.md). Она описывает два HTTPS-адреса для Aion и Ouroboros и управление службой из браузера.

На Windows нужен Python 3.12+; выполните `start.bat`. Ouroboros проверит WSL 2, Ubuntu и Docker Engine с Compose. Docker Desktop не требуется. На Linux используйте `bash start.sh`; хранилище ключей нужно разблокировать после запуска.

В настройках создайте проект в отдельной пустой папке **вне репозитория**, сохраните ключ архивов отдельно от компьютера и запустите Aion. Новая установка создаёт один проект и стартового администратора со случайным паролем. Существующие данные подключаются явно; пароли существующих аккаунтов не меняются.

Платформа доступна на `http://127.0.0.1:8000`; локальное управление — на `127.0.0.1:8787` с отдельной авторизацией. Одновременно работает один выбранный проект. Закрытие окна сворачивает Ouroboros в трей. Для завершения используйте действие выключения хаба и платформы.

## Возможности и ограничения

Работают аккаунты и роли, общие задачи доски и Ганта, зависимости, календарные таймеры, инциденты, уведомления, серверная аналитика, объяснимые правила Argus и зашифрованные копии. Argus не использует внешнюю модель. Markdown-документы доступны через API; редактора документов в интерфейсе нет.

MVP предназначен для локальной командной работы под наблюдением оператора. Автономная эксплуатация и публичный доступ требуют отдельной проверки окружения. Потерянный ответ на создание объекта может означать успешное сохранение: перед ручным повтором обновите данные. [Полный список ограничений](docs/10-known-limitations.md).
