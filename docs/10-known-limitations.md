# Известные ограничения

MVP подходит для локальной командной работы под наблюдением оператора. Эти ограничения нужно учитывать при эксплуатации и изменениях кода.

| Ограничение | Практическое действие |
| --- | --- |
| Идемпотентность создания реализована для задач с `creation_key`, но не для всех объектов | Форма задачи сохраняет ключ попытки; для остальных POST при потере ответа сначала проверить актуальные данные |
| Не все записи используют клиентскую версию | Для критичных правок сверять актуальные данные; версионирование задач и плана не распространять мысленно на все API |
| Hermes прекращает автоматические повторы временного отказа после трёх попыток | Оператор следит за error и повторяет после устранения причины |
| Неопределённая отправка могла дойти до Telegram | Проверить чат и явно принять риск дубля перед повтором; доставка ровно один раз не гарантируется |
| Нет общего ограничения запросов API/SSE | Не считать лимиты входа защитой от нагрузки; оценить внешний периметр перед публичной работой |
| Очереди и часть истории не имеют полной политики ограничения/очистки | Следить за размером БД и диском; последние 30/40/50 записей интерфейса не ограничивают хранилище |
| План не моделирует смены, навыки и вероятностный остаток | Проверять назначения и прогноз вручную; охват и неполнота показаны отдельно |
| Каскад инцидентов ограничен четырьмя уровнями | Не считать более глубокие последствия отсутствующими |
| Один процесс backend и одна выбранная установка | Не увеличивать число workers и не запускать две копии на одной БД |
| Управляемая поставка запрещает многопроектную песочницу и создание проекта через Aion | Проекты и отдельные тестовые установки создавать в Ouroboros |
| UI документов и отдельный экран аудита отсутствуют | Использовать сохранённый API при необходимости |
| Удаление аккаунта не очищает внешние сообщения, архивы и неизвестные псевдонимы | Учитывать сохранённые копии и ограничения обезличивания |
| Ключ архивов не меняется вместе с паролем аккаунта | Хранить отдельно; отдельной ротации ключа в панели нет |
| Linux-хранилище требует разблокировки; headless systemd-поставка отсутствует | Предусмотреть вход оператора после запуска |

## Проверки в целевом окружении

Перед автономной или внешней эксплуатацией отдельно подтвердите перезагрузку реального компьютера и автозапуск, перенос на другой ПК, длительную нагрузку, заполнение/отключение физического диска и восстановление после исчерпания попыток.

Telegram-сообщения и зашифрованные архивы используют разные пути доставки. Успешный getMe или текстовое сообщение не подтверждают отправку большого архива. Перед использованием удалённой копии получите зашифрованный файл в целевом чате и проверьте восстановление: сетевые/TLS-сбои могут помешать загрузке.

Для fxTunnel отдельно проверьте установленный CLI, переподключение, SSE, cookie входа и определение клиентского IP. Автоматические тесты и локальный health этих свойств не доказывают. Уже поставленные в очередь сообщения могут сохранить прежнюю публичную ссылку.
